# Neural Machine Translation System (English to Hindi)

An end-to-end Neural Machine Translation (NMT) Application that automatically translates English sentences into Hindi using an Encoder–Decoder architecture. Developed for Assignment 2 (GS-1).

---

## **Project Overview**

* **Application Domain:** Digital content localization and educational accessibility.
* **Target Users:** Non-English native speakers requiring access to regional language content.
* **Language Pair:** English (`en`) → Hindi (`hi`)
* **Dataset:** [AI4Bharat Samanantar Corpus](https://huggingface.co/datasets/ai4bharat/samanantar) (CC BY-NC 4.0 — non-commercial use; verify current terms on the dataset card before submission)
* **Dataset Size:** 48,724 cleaned sentence pairs (5–30 token length constraint applied)
* **Data Split:** 80% Train (38,979) / 10% Validation (4,872) / 10% Test (4,873)
* **Vocabulary Sizes:** English: 23,553 tokens | Hindi: 21,233 tokens
* **Fixed Sequence Length (`MAX_LEN`):** 34 (including `<sos>` and `<eos>`)

## **Model Architecture & Training (Task 3)**

* **Architecture:** Bidirectional LSTM Encoder + LSTM Decoder with **Bahdanau (additive) attention**, separate source/target embeddings.
* **Encoder:** Single-layer BiLSTM; final forward/backward states are projected (`Linear + tanh`) into the decoder's initial hidden/cell state.
* **Decoder:** LSTM that at each step attends over all encoder outputs, concatenates the resulting context vector with the token embedding, and predicts the next target token.
* **Loss:** Token-level cross-entropy, ignoring `<pad>` positions.
* **Decoding:** Both **greedy decoding** and **beam search** (configurable beam width, length-normalized scoring) are implemented for inference.

Run training with:

```bash
python train.py --epochs 15 --batch_size 128 --emb_dim 256 --hid_dim 512
```

Key optional flags: `--lr`, `--dropout`, `--clip` (gradient clipping), `--teacher_forcing_ratio`.

Outputs (written to `./models/`):

* `nmt_model.pt` — best checkpoint by validation loss, plus hyperparameters/vocab sizes needed to reload it.
* `loss_curve.png` — training vs. validation loss curve for the report.
* `training_log.json` — full per-epoch loss history and the hyperparameters used, for the report's training configuration table.

**Note on training time:** with ~39k training pairs, `hid_dim=512`, `emb_dim=256`, training on CPU will be slow (LSTMs are sequential). Use a GPU runtime (e.g. the BITS OSHA Virtual Lab GPU option, if available, or Colab) for the full run, or reduce `--epochs`/`--hid_dim` for a quicker demonstration run.

## **Application Development (Task 4)**

The project includes a Streamlit web application for English-to-Hindi translation.

### **Running the Application**

Make sure Python 3.12 or later is installed.

Create and activate a virtual environment:

```bash
python -m venv .venv
```

For Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

The trained model and vocabulary files required by the application are located in:

```text
models/nmt_model.pt
data/src_vocab.json
data/tgt_vocab.json
```

Start the Streamlit application using:

```bash
streamlit run app.py
```

The application will be available locally at:

```text
http://localhost:8501
```

### **Application Features**

The application provides:

1. **Single-sentence translation** — Users can enter English text and view the generated Hindi translation.
2. **Greedy decoding** — Generates a translation using greedy decoding.
3. **Beam-search decoding** — Provides beam-search decoding with a configurable beam width.
4. **Batch translation** — Users can upload a `.txt` file containing one English sentence per line or a `.csv` file containing English sentences.
5. **Original and translated text display** — The application displays the English input alongside the generated Hindi translation.
6. **CSV output** — Batch translation results can be downloaded as a CSV file.

### **Batch Input Format**

For a `.txt` file, provide one English sentence per line:

```text
How are you today?
This is a very important meeting.
The government announced a new policy for farmers.
```

For a `.csv` file, include an `english` column:

```csv
english
How are you today?
This is a very important meeting.
The government announced a new policy for farmers.
```

### **Known Limitations**

The application uses the trained NMT checkpoint generated during Task 3. Translation quality may vary, particularly for long sentences, rare or unseen words, named entities, and sentences with structures that are not well represented in the training data.

The model may occasionally generate `<unk>` tokens or repeated words/phrases. These limitations are considered during the evaluation of the generated translations.
